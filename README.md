# Warsaw Saturday café crawl

A single static page: 23 coffee and bakery stops across Warsaw in riding order,
with Saturday opening hours, the ride from the previous stop, a tick box per
stop, and the three Google Maps cycling legs that join them.

Ticks are kept in the browser's local storage, so they are per device and
survive a reload. There is no build step — `index.html` is the whole site.

Hosted with GitHub Pages from the default branch, root folder.
